Windows computers

Windows 10 and 11 have Microsoft Quick Assist built in, so there's nothing to download.

  1. Call me. I'll give you a short security code.
  2. Press Ctrl + Windows key + Q together. (Or click Start and type Quick Assist.)
  3. Type in the code I give you and click Submit.
  4. Click Allow to let me see and work on your screen.

Macs, Chromebooks and everything else

Use Google's free Chrome Remote Desktop.

  1. Call me, then open remotedesktop.google.com/support in the Chrome browser.
  2. If asked, sign in with a Google account and install the small helper it offers.
  3. Under Get Support, click Generate Code.
  4. Read me the code, then click Share when asked.

You stay in control

You'll see everything I do on your screen. To end the session at any time, just close the window or click Stop Sharing.
